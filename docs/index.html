Description

Schema for describing the EUREMAP marine natural-product bioprospecting service pipeline as a knowledge graph: who offers which service, at which pipeline step, through which research infrastructure, in which country, with which techniques, what it consumes and what it produces. It acts as the semantic control plane for service discovery, routing and governance; it does not store scientific payload data.
